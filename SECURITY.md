# Security and disclosure

This repository is a research portfolio and is not a clinical decision-support or therapeutic tool.

Please do not include passwords, access tokens, private Drive URLs, personally identifiable data or proprietary datasets in issues, pull requests or examples.

If you find a credential or sensitive file in the repository or its history, contact the repository owner privately through GitHub before disclosing the issue publicly. Rotate exposed credentials and review the full history as appropriate.

Automated CI currently covers synthetic-data Python smoke tests; it is **not** a full security scan, full workflow reproduction or scientific validation.
